# OpenAccountants marketplace

One Claude Code plugin: **openaccountants**. It connects Claude Code to the OpenAccountants server, which holds tax and accounting skills for 190+ jurisdictions. Each skill sets out the method for a tax task, names the official source for its figures, and says whether a licensed accountant has approved it.

```bash
claude plugin marketplace add openaccountants/marketplace
claude plugin install openaccountants@OpenAccountants
```

See [plugins/openaccountants](plugins/openaccountants) for the commands. Other apps (Claude.ai, ChatGPT, Cursor): [openaccountants.com/connect](https://www.openaccountants.com/connect).

The other folders under `plugins/` are older per-country packs that are no longer listed in this marketplace.
