# OpenAccountants — Oil Gas Extractives (vertical)

Use this skill whenever a producer, refiner, miner, oilfield services company, midstream operator, or LNG developer asks about sector-specific tax and accounting. Trigger on phrases like "petroleum revenue tax", "PRT", "ring-fence corporation tax", "RFCT", "supplementary charge", "energy profits levy", "EPL", "OBPS", "carbon levy", "EU Solidarity Contribution", "windfall tax energy", "Norwegian sp

Skills include accountant-reviewed versions and source-cited drafts. Check each fetched skill version's review status, reviewer and review date in the [current catalogue](https://www.openaccountants.com/skills).

## Install

```bash
claude plugin install openaccountants/openaccountants-vertical-oil-gas-extractives
```

Or browse the full marketplace:

```bash
claude plugin marketplace add openaccountants/marketplace
```

## Slash commands

- `/start` — scope a workflow and load the right skills
- `/skills` — list every skill in scope
- `/review` — request a licensed accountant to review your work
